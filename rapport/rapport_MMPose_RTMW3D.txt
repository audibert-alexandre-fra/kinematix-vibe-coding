2. INSTALLATION — SUCCÈS (difficile)
  - mmcv n'a pas de roues pour macOS arm64 : compilation depuis les sources (mmcv 2.1.0 avec ops,
    ≈ 10 min) dans un environnement séparé third_party/envs/mmpose (Python 3.10, torch 2.1.2,
    numpy < 2). Il faut setuptools < 70 (pkg_resources) et --no-build-isolation.
  - mmpose installé en mode éditable : les configs "mmpose::..." sont introuvables (dossier .mim
    absent) -> installation non éditable.
  - Python système sans certificats SSL : poids téléchargés avec curl dans weights/mmpose/.
  - Script : tools/run_rtmw3d.py -> weights/rtmw3d_cache/ ; backend `--backend rtmw3d`.

3. SORTIES ET INTÉGRATION
  133 points COCO-WholeBody (corps, pieds : gros orteil, petit orteil, talon ; visage ; mains) :
  coordonnées pixels (x, y) + profondeur RELATIVE au bassin z (m). La profondeur absolue n'est pas
  prédite (le code d'exemple suppose une focale et une profondeur fixes) : nous l'estimons image
  par image en cherchant la profondeur du bassin Z0 pour laquelle les segments rétro-projetés
  (cuisse, jambe, bras, avant-bras, tronc, pied, largeurs bassin/épaules) ont leur longueur
  anthropométrique (médiane pondérée, filtre médian temporel ; models/cached.py), l'échelle
  exacte étant ensuite recalée par la taille connue lors de la calibration.

4. DIFFICULTÉS
  - Le détecteur RTMDet (plus grande personne) choisissait sur gait1/cam0 une personne coupée au
    premier plan -> la même détection que les autres modèles est utilisée (RF-DETR + suivi).
  - Profondeur relative peu fiable : corrélation 0,53–0,60 avec celle de MeTRAbs, amplitude
    ≈ 1,3 x trop grande (échelle de données recalée 0,75–0,90 au lieu de ≈ 1).

5. TEMPS D'INFÉRENCE (CPU M3 Pro)
  - Seul sur la machine : ≈ 0,51–0,54 s/image (dont détection RF-DETR ≈ 0,06–0,07 s) ; avec un autre
    calcul en parallèle : 0,7–1,2 s/image. Pipeline complète 55–353 s par vidéo
    (gait2 1080x1920, 305 images, mesurée en parallèle d'un autre calcul : > 5 min ; ≈ 170 s estimées seule).
  - GPU (estimation) : RTMW3D-L ≈ 10–15 ms/personne (RTX 3090/4090, FP16), RTMDet-m ≈ 10 ms ->
    ≈ 25 ms/image.
